
# Паспорт проекта Telegram-бота

## О проекте
Бот-консультант по услугам вайбкодинга. Отвечает потенциальным клиентам, рассказывает о услугах и проектах.

## Бот
- **Название:** Evrat_first_tele_bot
- **Username:** @Evrat_First_Tele_bot
- **Библиотека:** aiogram 3.x
- **Токен:** хранится в `.env`, НЕ в этом файле


## Команды
- `/start` — приветствие и меню
- `/help` — справка
- `/about` — информация о владельце
- `/services` — услуги
- `/projects` — портфолио
- `/contact` — контакты

## Правила
1. Токен ТОЛЬКО в `.env`
2. Не публиковать токен в репозиториях
3. При добавлении новых команд — обновлять `/help`
