Паспорт бота-консультанта по услугам вайбкодинга
1. Цель и задачи
Цель: автоматизировать первые ответы потенциальным клиентам, которые хотят заказать разработку лендингов, MVP или AI-продуктов, и подводить их к оставлению заявки.

Задачи:

Отвечать на вопросы о портфолио и услугах в любое время суток.

Рассказывать о проектах (включая планировщик завода Arknights) и технологиях.

Собирать контакты клиентов и передавать заявки владельцу.

Сократить количество однотипных вопросов в мессенджерах.

2. Целевая аудитория
Предприниматели, стартаперы и владельцы бизнеса, которым нужен быстрый MVP или лендинг.

Разработчики и проджект-менеджеры, ищущие специалиста по вайбкодингу для своих проектов.



3. Функции бота
Со стороны пользователя:

Получать информацию о вайбкодер-услугах (лендинги, MVP, AI-автоматизация, UI/UX).

Узнавать о портфолио и проектах (включая планировщик завода Arknights).

Связываться с владельцем, если вопрос сложный.

Оставлять заявку на консультацию или заказ услуги.

Со стороны владельца:

Получать уведомления о новых заявках.

Видеть контакты пользователей.

(в следующих версиях) Просматривать простую статистику обращений.

4. Сценарии использования
Сценарий 1. Вопрос по услугам

Пользователь нажимает /start → Бот приветствует и показывает краткое меню → Пользователь выбирает «Услуги» → Бот отправляет описание услуг → Пользователь задаёт уточняющий вопрос → Бот отвечает на основе базы знаний.

Сценарий 2. Вопрос по проекту (портфолио)

Пользователь выбирает «Проекты» → Бот показывает список проектов (включая планировщик Arknights) → Пользователь запрашивает подробности → Бот рассказывает о проекте, технологиях и результатах.

Сценарий 3. Заявка на услугу

Пользователь решает заказать услугу → Бот запрашивает контакты (имя, Telegram/email) → Пользователь оставляет контакты → Бот фиксирует заявку и уведомляет владельца → Владелец связывается с клиентом.

6. Ограничения и риски
Ограничения первой версии:

Бот работает только с текстом (без изображений и файлов).

Бот отвечает только на основе загруженной базы знаний.

Бот не принимает онлайн-оплату (добавим позже).

Память сбрасывается при перезапуске (база данных будет позже).

Риски и способы решения:

Риск	Решение
ИИ даёт неточный ответ	Бот отвечает строго по базе знаний. Если ответа нет — передаёт вопрос владельцу.
Утечка токена бота	Токен хранится только в файле .env, который не попадает в Git.
Бот не отвечает	Проверить, запущена ли программа, и правильно ли вставлен токен.
Пользователь пишет не по шаблону	Бот обрабатывает любые текстовые сообщения и старается дать ответ по базе знаний.
7. Требования к каркасу (MVP)
Минимальный набор команд:

/start — приветствие + меню (кнопки или текст).

/help — краткая справка о возможностях бота.

/about — информация о владельце и его специализации.

/services — описание услуг (лендинги, MVP, AI-автоматизация, UI/UX).

/projects — список проектов (включая планировщик Arknights).

/contact — контакты владельца и предложение оставить заявку.

Обработчики:

Команды (/start, /help, /about, /services, /projects, /contact).

Текстовые сообщения (бот отвечает на основе базы знаний).

Кнопки: Inline-кнопки для удобной навигации (например, «Услуги», «Проекты», «Связаться»).

8. Успешные критерии бота после сборки каркаса
Бот зарегистрирован в Telegram через @BotFather.

Токен добавлен в файл .env.

Команда /start работает и показывает приветствие с меню.

Бот отвечает на команды /help, /about, /services, /projects, /contact.

Бот не падает при неизвестных сообщениях (хотя бы пишет «не понял, вот что я умею»).

Приложение запускается без ошибок и висит в консоли.
